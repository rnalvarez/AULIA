# Migración desde CHIONIA

Esta rama conserva el vínculo con CHIONIA como caso piloto, pero separa el contenido del autor de la infraestructura.

## Trasladado

- conceptos seleccionados a JSON;
- bibliografía;
- ejemplos;
- cuatro modalidades de interacción;
- actividades;
- contrato de tracking;
- experiencia básica de chat;
- separación conceptual entre recuperación, pedagogía, LLM y seguimiento.

## Deliberadamente no trasladado al CORE

- identidad/personificación de Michel Chion;
- system prompt extenso;
- endpoints reales;
- padrón de una comisión;
- credenciales concretas;
- datos personales;
- código legado de modelos locales.

## Próxima migración

La siguiente etapa debe incorporar un mecanismo para cargar cualquier course pack sin editar el registro de cursos, idealmente desde una configuración publicada por el docente.
