# Course pack template

Copiá esta carpeta para crear una nueva cátedra.

Archivos esperados:

- course.json — identidad del curso.
- bibliography.json — bibliografía autorizada.
- concepts.json — unidades de conocimiento.
- examples.json — ejemplos/obras/casos.
- modes.json — modalidades de interacción.
- activities.json — actividades pedagógicas.

La regla del proyecto es que estos archivos describen el curso; no contienen lógica de la aplicación.
